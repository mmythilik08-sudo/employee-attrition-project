About Project

The Employee Attrition Prediction System is a Machine Learning web application that predicts whether an employee is likely to Stay or Leave the organization based on employee details. This system helps HR teams identify employees at risk and make better decisions to improve employee retention.

🎯 Objective

Predict employee attrition and support HR decision making.

⚙️ Technologies

Python, Flask, HTML, CSS, Machine Learning.

📊 Dataset

1470 Employee Records
Accuracy: 87.4%

🚀 Features

✔ Login System
✔ Employee Prediction
✔ Stay / Leave Result
✔ Reasons & Suggestions
